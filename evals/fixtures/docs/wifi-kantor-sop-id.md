# SOP: Gangguan Wi-Fi kantor (sintetis)

Versi 1.0. Pemilik: tim jaringan.

## Pemeriksaan awal
1. Tanyakan lantai dan ruangan pengguna, serta jam gangguan mulai terjadi.
2. Jika lampu access point berkedip merah, periksa kabel PoE dari access point ke switch lantai.
3. Perangkat tamu harus terhubung ke SSID KANTOR-TAMU yang berada di VLAN 40; perangkat karyawan memakai VLAN 20.

## Eskalasi
Jika lebih dari tiga access point di satu lantai mati bersamaan, eskalasi ke tim jaringan sebagai SEV3 dalam 15 menit.
